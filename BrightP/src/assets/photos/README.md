# Portal photography

The images in this folder are downloaded from [Unsplash](https://unsplash.com) and used under the
[Unsplash License](https://unsplash.com/license) (free for commercial use, no attribution required,
but appreciated). They are mapped to services and destinations in `src/portal/photos.js`.

Replace any of them with licensed brand photography by overwriting the file (keep the file name)
or by editing the import in `photos.js`. Keep each image under ~400 KB so the portal stays fast.
